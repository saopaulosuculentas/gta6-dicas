Código de dinheiro do GTA 6: US$ 250 mil na hora

O código de dinheiro do GTA 6 dá US$ 250.000 de uma vez. A sequência é só no direcional, mas ele só libera depois de zerar a história.

Como ativar
Abra o celular do jogo (direcional para cima), segure L1 + R1 e digite a sequência no direcional.

O que faz: Coloca US$ 250.000 na carteira na hora.

O código de dinheiro do GTA 6 entrega US$ 250.000 de uma vez. A sequência usa só o direcional: cima, direita, baixo, esquerda, cima, esquerda, baixo, direita. A lista saiu no TechTudo em 18 de novembro, antes do lançamento oficial.

Como digitar

  1. Aperte o direcional para cima para abrir o celular do personagem.
  2. Segure L1 e R1 ao mesmo tempo.
  3. Sem soltar, digite no direcional: cima, direita, baixo, esquerda, cima, esquerda, baixo, direita.

O que precisa para liberar

Este não é um código para começo de jogo. Segundo o TechTudo, o requisito é concluir a história. Antes disso a sequência não faz nada.

O que você precisa saber

  • Ativar código desabilita os troféus, de acordo com a mesma matéria. Salve antes.
  • No Xbox as fontes divergem sobre qual par de botões segurar: o equivalente direto de L1 e R1 é LB e RB, mas o TechTudo fala em LT e RT. Teste os dois.
  • Ainda não vimos este código funcionando em vídeo. Por isso o selo é “Em verificação”. Assim que um canal mostrar, a página é atualizada.

Perguntas rápidas

Qual é o código de dinheiro do GTA 6?

Segundo o TechTudo: cima, direita, baixo, esquerda, cima, esquerda, baixo, direita, digitado no celular do jogo com L1 e R1 seguros. Dá US$ 250.000.

O código de dinheiro funciona no começo do jogo?

Não. De acordo com a mesma fonte, ele só é liberado depois de concluir a história principal.

Usar o código de dinheiro tira os troféus?

Sim. Segundo o TechTudo, ativar qualquer código desabilita os troféus do jogo.
